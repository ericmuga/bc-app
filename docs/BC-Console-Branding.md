# BC Console branding

Asset: `client/public/branding/bc-console.png`, used on the login screen and as the browser favicon and touch icon.

Created using the built-in image generation tool. The cart represents commerce and the ascending bars represent analytics, using teal to match the console's Business Central theme.

## Generation prompt

Create a single polished application logo icon for BC Console, a Business Central ERP commerce and analytics console. Square 1024x1024 image with genuinely transparent background. No text or letters. One bold, minimal geometric shopping cart whose basket consists of three ascending solid rounded bars, combining commerce, inventory/business management, and analytics in one unified symbol. Strong teal and turquoise palette (#1a9ea1, #35d3cf), small blue accent allowed. Thick clean cart base and two circular wheels. Flat vector-like shapes, crisp edges, no shadows, no gradients, no 3D, no mockup, no surrounding frame. Center the icon and fill about 82 percent of the canvas. Extremely simple memorable silhouette, legible as a browser favicon at 32px and on dark navy login screen. Professional enterprise software identity. Return only the single icon.
